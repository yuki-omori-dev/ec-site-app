# ec-site-app
Spring BootとReactで構築したフルスタックECサイトを動かす実習。

## アプリの概要とスクリーンショット、あるいはデモGIF

個人経営者のオンライン取引を実現するための仮想ECサイト。

(完成後にスクリーンショットなどを貼り付ける)

## 開発の動機・目的

Javaのバックエンド開発スキルに加え、フロントエンドとのAPI連携や、トランザクションを伴う実務的なデータ設計(在庫管理、注文処理)を一貫して実装・習得するために開発を進行中。

## 技術スタックと選定理由

- Java/Spring Boot:業務システムでの採用実績が多く、型安全なAPI開発とSpring Data JPAによる効率的なDB操作を行うため。
- JavaScript/React:コンポーネント指向による再利用性の高いUI構築と、非同期通信(SPA)による快適な操作性を実現するため。 
- PostgreSQL:ECサイトに不可欠な整合性・トランザクション管理を確実に行うため。
